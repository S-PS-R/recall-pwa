## Milestone delivery

The user has requested that every completed milestone be pushed to the project's GitHub repository.

- Complete the milestone's implementation and relevant verification before pushing.

- Update README with completed features, validation results, limitations and deployment changes.
- Commit and push the completed milestone to the configured origin. Create an annotated `milestone-N` tag when that milestone is first completed; never move an existing milestone tag.
- Keep secrets, imported user files, local databases, dependency folders, build output and test artifacts out of Git.
- GitHub Pages deployment is manual through the workflow unless the user requests otherwise. Do not claim that a push has deployed the site.
